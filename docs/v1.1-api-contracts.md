# myPilotPost — V1.1 API Contracts (Production Grade)

> [!IMPORTANT]
> **Contract-Locked Rule**: All response keys are contract-locked. They must not be renamed, removed, or restructured without versioning the API.
> 
> **ISO8601 Date Rule**: All timestamps must be ISO8601 strings (UTC).
> 
> **No Null Rule**: No endpoint may return `null` for arrays, objects, or numeric values. Empty lists must be `[]`, counts must be `0`.
> 
> **Safety Rule**: All new endpoints must follow existing naming, pagination, and response conventions defined in this document.

## Global Error Shape
```json
{
  "error": "Human readable message",
  "code": "MACHINE_READABLE_CODE",
  "detail": "Optional technical detail or null"
}
```

## 1. Pagination (Standard for all lists)
All array-returning endpoints include a `pagination` block:
```json
{
  "pagination": {
    "limit": 20,
    "offset": 0,
    "total": 120
  }
}
```

## 3. Brand Intelligence
`GET /api/customer/brand-intelligence`

### Score Mapping
- **0–40**: `critical` (Immediate action required)
- **41–70**: `warning` (Attention needed)
- **71–100**: `good` (No action required)

### Response Structure
```json
{
  "brandHealth": { "score": 85, "status": "good", "summary": "..." },
  "contentReadiness": { "drafts": 5, "ready": 2, "scheduled": 10, "gaps": [] },
  "publishingConsistency": { "postsThisWeek": 4, "missingDays": ["Sunday"], "cadenceStrength": "medium" },
  "campaignMomentum": { "active": 2, "inactive": 1 },
  "integrations": { "connected": 3, "missingRecommended": ["instagram"] },
  "marketContext": { "country": "ZW", "language": "en", "localizationStatus": "partial" },
  "seoSignals": { "articleCount": 8, "missingMetadata": 0, "status": "good" },
  "topAlerts": [ { "type": "schedule_gap", "message": "..." } ],
  "recommendedActions": ["Schedule drafts"]
}
```
